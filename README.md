# SoloFácil

**Análise de solo e manejo inteligente**  
MVP do Projeto Agro (futura vertical da Labzetta)

Foco: **Milho no Ceará**

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (preparado)
- Motor de regras agronômicas rastreável

## Como rodar

```bash
npm install
npm run dev
```

Acesse: http://localhost:3000

## Páginas principais

- `/` → Dashboard inicial
- `/diagnostico/novo` → Nova análise
- `/diagnostico/resultado` → Tela de resultado (estilo do mockup)
- `/diagnosticos` → Lista de diagnósticos

## Observação

A tela de resultado (`/diagnostico/resultado`) foi construída para ficar o mais próxima possível do design de referência (SoloFácil).
